MacBedrock / Pull request walkthrough

Make Bedrock setup accessible on Apple Silicon Macs

A native companion installs a verified community launcher and guides the player from macOS setup to their own Google Play copy of Minecraft.

Apple SiliconmacOS 14+Google Play ownership required
01 / How it works

A practical bridge to the existing runtime.

Before: The official launcher does not provide a macOS Bedrock client. The player has to discover, install, and configure an unofficial route.
01 → MACBEDROCK

Check the Mac

Detect Apple Silicon and macOS 14+. Show ownership and compatibility requirements.

02 → VERIFIED INSTALL

Get the launcher

Download release 0.1.13. Verify SHA-256, mount read-only, validate and stage the app.

03 → UPSTREAM APP

Sign in & download

The community launcher handles Google Play, game versions, runtime, and patches.

04 → MINECRAFT

Press Play

The player starts an owned compatible game version. Microsoft login happens in-game.

MacBedrock is a setup companion, not a new Minecraft port. No game files or account credentials are bundled. Latest versions, Realms, and multiplayer remain subject to upstream compatibility.
02 / Decisions & recovery

Handle macOS rejection honestly.

Downloads stay verifiable

A pinned checksum is checked before installation. Copying happens beside the destination, then an atomic move commits it. Existing apps and worlds are not overwritten.

Quarantine stays enabled. A valid download is not equivalent to a notarized app.

When macOS moves it to Trash

The unsigned upstream release was rejected during local verification. The app now detects removal and launcher termination, and describes a launch request without claiming gameplay success.

A separate Xcode 26+ recovery script compiles a pinned upstream source commit locally without disabling Gatekeeper.

03 / What to look at

Five places tell the story.

Sources/MacBedrockCore/Launcher.swift

Hardware checks, pinned release verification, bundle validation, staged installation and cleanup.

Sources/MacBedrock/MacBedrockApp.swift

Native screens, install progress, launch handoff, removal detection and recovery guidance.

scripts/build-launcher-from-source.sh

Optional local source build for Macs with Xcode; pins the upstream commit and preserves existing installs.

Tests/MacBedrockCoreTests/LauncherTests.swift

Corruption, incompatible hardware, malformed apps, safe staging and opt-in real download coverage.

scripts/build-app.sh

Builds, locally signs and packages the Apple Silicon app; CI publishes the ZIP as a build artifact.

04 / How to verify

Test the install. Then follow the player.

swift test
MACBEDROCK_LIVE_INSTALL_TEST=1 swift test
scripts/build-app.sh
open dist/MacBedrock.app

# If macOS rejects the downloaded launcher (requires Xcode 26+):
scripts/build-launcher-from-source.sh
  1. Open Play, Setup guide, and Help & about; confirm requirements are clear.
  2. Install the launcher. Confirm status changes and the Open button appears.
  3. Open it; check any macOS first-open prompt. If moved to Trash, return to MacBedrock and confirm it reports removal.
  4. Use a Google Play account that owns Minecraft to download a supported version, then press Play.
Verification boundary: Installer tests include a real verified download. Account authentication and a running Minecraft game require the player’s credentials and owned game; the walkthrough does not claim those have been tested.
